# Python To-Do List Application

A simple command-line To-Do List application built using Python.

## Features

- Add tasks
- View tasks
- Delete tasks
- Input validation
- Error handling using try, except, else, and finally
- Menu-driven interface

## Technologies Used

- Python 3

## How to Run

1. Clone the repository.

```bash
git clone [https://github.com/yourusername/Todo-List-App.git](https://github.com/ritvik250111/todo_list.git)
```

2. Navigate to the project folder.

```bash
cd Todo-List-App
```

3. Run the program.

```bash
python todo_list.py
```

## Example Menu

```
1. Add Task
2. View Tasks
3. Delete Task
4. Quit
```
